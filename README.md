# 🌾 Harvest Moon: Friends of Mineral Town - Progress Tracker

PWA interaktif untuk melacak progres dan sebagai panduan lengkap game Harvest Moon: Friends of Mineral Town (GBA).

## Fitur Aplikasi (15 Kategori)

1. **Tanaman Kebun** — Dikelompokan per musim, harga, waktu panen, rekomendasi
2. **Tanaman Liar** — Item forage per musim dan harga jual
3. **Raja Ikan** — 6 ikan legendaris, lokasi, syarat, dan harga
4. **Power Berries** — 10 lokasi + 1 Mystic Berry (trackable ✅)
5. **Jewels** — Truth, Goddess, Kappa Jewels (trackable ✅)
6. **Ore & Upgrade** — Bahan tambang dan jalur upgrade alat di atas Mystrile
7. **Special Item Tambang** — Item di Spring Mine dan Lake Mine
8. **Event Desa** — Festival per musim, jadwal, dan hadiah (trackable ✅)
9. **Event NPC** — Event penduduk non-pasangan (trackable ✅)
10. **Heart Events** — Event romantis 5 bachelorette (trackable ✅)
11. **Kesukaan Warga** — Hadiah favorit warga non-pasangan
12. **Kesukaan Pasangan** — Hadiah favorit 5 bachelorette
13. **Resep Makanan** — Bahan dan alat masak per kategori
14. **Telur, Susu, Wol** — Cara mendapatkan kualitas Gold/P/X
15. **Hadiah** — Item dari warga via event/pertemanan (trackable ✅)

## Tech Stack

- **Vue 3** + Vite
- **Pinia** (State Management + LocalStorage persist)
- **Vue Router 4**
- **Lucide Vue** (Icons)
- **vite-plugin-pwa** (Installable PWA)

## Cara Menjalankan

```bash
npm install
npm run dev
```
